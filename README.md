**Smart Password Strength Checker Using Finite Automata**

Project Title:
**“SecurePass: A DFA-Based Password Validation and Security Analyzer”**

Project Idea:
Create a password checker that uses DFA to determine whether passwords satisfy security requirements such as
length, uppercase letters, numbers, and special characters.

Automata Concepts: 

• DFA/NFA
• Regular Expressions
• Pattern Recognition
• Regular Languages Features:
• Password validation
• Strength classification
• Rule violation detection
• State transition visualization
