SecurePass

Every character you type is fed into a deterministic finite automaton (DFA). It accepts only if the password is long enough and contains an uppercase letter, lowercase letter, digit and special character.

Rule check (regular expressions)

    Each rule is a regular language, so a DFA can recognise it. Combining them by intersection gives one DFA for the whole policy.

    Pattern recognition

      Repeated runs, keyboard/alphabet sequences and common words are finite sets of strings, so they are regular too. No backreferences are used; the regexes are generated by listing every case.
